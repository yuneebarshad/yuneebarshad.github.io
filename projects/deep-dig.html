Overview

ROLE: Senior Game Developer — Gameplay Systems & Progression

Deep Dig is a mobile first-person mining and resource-progression game developed in Unity for Android. I built the project-specific gameplay systems around a customized Unity Starter Assets first-person controller, including camera-based contextual interactions, ore inventory and selling, cash progression, ScriptableObject-driven equipment upgrades, battery and jetpack mechanics, guided onboarding, hybrid persistence, mobile UI and AppLovin MAX integration. The game combines first-person exploration with resource collection and an upgrade-driven progression loop, while a physics-based lawn-mower sequence introduces movement and interaction mechanics before the main mining experience.

⚙

Framework note: Unity Starter Assets provides the first-person controller foundation. Digger, Cinemachine, DOTween and AppLovin MAX are third-party technologies I integrated or customized around the game-specific systems. Digger is described only as a terrain integration; its voxel, Marching Cubes, Jobs and Burst internals are not claimed as my implementation.

Gameplay Loop

Explore mining environment→ Locate & collect ores→ Manage inventory capacity→ Sell resources for cash→ Purchase equipment upgrades→ Improve tools & capacity→ Continue resource progression

Key Highlights

  • Implemented a camera-centered context-sensitive interaction system using Physics.Raycast and LayerMasks for terrain, ores, selling and shop interactions.
  • Built an event-driven ore inventory and economy system with stacking, capacity limits, selling, cash progression and animated UI feedback.
  • Created a data-driven equipment progression system using ScriptableObjects for shovel, inventory, battery and jetpack upgrades.
  • Engineered a state-driven onboarding finite-state machine coordinating movement, camera guidance, mower gameplay, mining, inventory, selling, upgrades and saving.
  • Developed a physics-driven lawn-mower gameplay sequence using Rigidbody movement, camera-relative input, trigger detection, completion tracking, particles and audio.
  • Implemented hybrid local persistence using JSON, PlayerPrefs, unique world-object IDs and coordinated save-state management, alongside AppLovin MAX mobile advertising.

Core Systems

✓Mobile First-Person Controls(Starter Assets Customization + Mobile Input)

Customized Unity Starter Assets' first-person controller for mobile gameplay and connected it with touch-camera input and Cinemachine targeting.

  • Uses CharacterController for collision-aware first-person movement with configured walk, sprint and acceleration behaviour
  • Routes virtual-joystick input through Unity's mobile input flow into the player controller
  • Implements touch-drag camera yaw and pitch with clamping and interpolation
  • Includes grounded detection, footsteps and surface-aware movement feedback
  • Uses Cinemachine camera targeting while preserving the Starter Assets movement foundation
✓Context-Sensitive Interaction System(Physics.Raycast + LayerMask + UI)

Implemented a camera-centered targeting system that reuses the mobile interaction UI and changes available actions according to the object under the player's crosshair.

  • Uses Physics.Raycast from the camera and LayerMask filtering to restrict interaction checks to gameplay targets
  • Targets terrain for digging requests, ores for collection, the computer for selling and the shop for upgrades
  • Reuses Dig and Hand controls contextually instead of maintaining separate buttons for every object type
  • Assigns and updates UnityEvent listeners at runtime as the current target changes
  • Separates player targeting and interaction responsibilities across partial PlayerHandler implementations
✓Guided Onboarding & Lawn-Mower Gameplay(FSM + Rigidbody + Tutorial UI)

Engineered a state-driven onboarding flow that introduces the complete first-session loop and temporarily switches the player into a physics-based mower control mode.

  • Coordinates movement, touch-camera control, mower targeting, grass cutting, mining, ore collection, selling, upgrading and saving
  • Uses trigger volumes, camera-target checks, UnityEvents, inventory C# events, button listeners and coroutines to advance tutorial state
  • Dynamically attaches focused tutorial helper components and uses stencil-based UI highlighting for required actions
  • Disables the normal player while mowing and redirects virtual-joystick input to camera-relative Rigidbody movement
  • Uses trigger collisions, percentage-based completion, particle effects and audio feedback for the mower sequence
✓Ore Inventory, Selling & Economy(Events + Dynamic UI + DOTween)

Built an event-driven resource inventory and selling loop supporting Bronze, Silver, Crystal and Gold ores with quantity-based capacity and cash progression.

  • Stacks collected ores by type while tracking total item quantity against inventory capacity
  • Publishes inventory usage and full-state events so UI can react without direct polling
  • Dynamically creates selling rows showing ore name, quantity, unit value and subtotal
  • Calculates the combined sale value, clears sold inventory and updates the persistent cash balance
  • Uses DOTween for floating cash feedback, movement, scaling and animated balance transitions
✓ScriptableObject Upgrade Progression(Data-Driven Design + Event-Driven UI)

Created a data-driven equipment progression system that keeps upgrade configuration separate from runtime purchase and UI logic.

  • Uses ScriptableObject assets to define shovel, inventory, battery and jetpack upgrade tiers
  • Stores each tier's level label, purchase cost, gameplay effect and player-facing description as data
  • Applies purchased upgrade values through a centralized UpgradeManager
  • Updates shop sliders, affordability states, next costs and effect descriptions through upgrade events
  • Connects upgrade purchases directly to the mining economy and equipment progression loop
✓Battery & Jetpack Systems(Resource System + CharacterController Extension)

Implemented interconnected battery and jetpack gameplay systems layered over the customized first-person controller.

  • Connects battery consumption to digging and jetpack activation through mobile pointer input
  • Updates battery capacity, recharge interactions and HUD feedback through the shop and gameplay UI
  • Adds jetpack vertical movement and gravity handling over the existing CharacterController movement foundation
  • Reads the same mobile movement input for horizontal control while airborne
  • Links battery and jetpack progression into the ScriptableObject-driven upgrade system
✓JSON Save Data & Persistent Progression(Hybrid Persistence + DTO Serialization)

Designed a hybrid local persistence workflow using different storage mechanisms for lightweight state, structured progression data and world-object state.

  • Uses PlayerPrefs for lightweight values such as cash and tutorial completion
  • Serializes upgrade levels, battery state, inventory capacity and inventory contents through JSON
  • Converts runtime inventory entries into JSON-friendly data-transfer objects for save and restore
  • Tracks collected ores through persistent world-object identifiers so previously collected resources can be removed after loading
  • Coordinates manual save actions across ore state, structured progression data and the integrated terrain persistence layer
✓Mobile UI, Audio & AppLovin MAX(UI + Audio Service + SDK Integration)

Integrated the runtime presentation and mobile-service layer around the core mining and progression systems.

  • Centralizes Dig and Hand controls, inventory/shop panels, capacity feedback, ore pickup animations, battery, jetpack, save and pause UI
  • Uses TextMeshPro and DOTween for readable mobile feedback and animated economy presentation
  • Provides a persistent named-sound registry for menu/gameplay music, interaction feedback, digging, cash changes and tutorial audio
  • Integrated AppLovin MAX interstitial and rewarded advertising with loading, retry handling, timed placement logic and lifecycle callbacks
  • Configured the Android project around URP, IL2CPP, ARMv7/ARM64, landscape orientation, Vulkan and OpenGL ES 3 support

Overview

ROLE: Senior Game Developer — Framework Extension, Production Systems & LiveOps

Internet Cafe Empire is a released Android and iOS idle-management game built on the licensed Perfect Hotel framework as its starting foundation. I adapted the inherited hotel-management structure into an internet-cafe experience while preserving its Observer Pattern and existing system relationships. My work included a complete rework of levels 2 and 3; implementing level-based quests and mobile UI flows; building rewarded-video spawning and reward logic for the scooter, roller skates, bouncer, money bag and magnet boost; implementing purchase and persistent-ownership flows with Unity IAP; coordinating thief, feedback and garbage-man events; integrating AppLovin MAX, Firebase, Remote Config and Tenjin; and developing backward-compatible JSON save migration and reconciliation for existing players.

Gameplay Loop

Earn cash→ Unlock room→ Upgrade & hire staff→ Complete quest→ Handle live event→ Expand cafe

Key Highlights

  • Adapted the licensed Perfect Hotel foundation into an internet-cafe management game while preserving the existing Observer Pattern and system relationships.
  • Completely reworked levels 2 and 3, including progression, rooms, staff, utilities and internet-cafe content for arcade, racing, console and VR areas.
  • Implemented level-based quests and mobile UI flows for progression, events, rewarded videos, purchases, utilities and boosts.
  • Built thief, feedback and garbage-man event systems with their gameplay state, UI flow, triggers and rewards.
  • Built rewarded-video spawning and reward logic for the scooter, roller skates, bouncer, money bag and magnet boost, connected with permanent IAP ownership.
  • Integrated Unity IAP, AppLovin MAX, Firebase Analytics, Remote Config and Tenjin across monetization, analytics, tuning and attribution flows.
  • Developed backward-compatible JSON save migration and reconciliation to preserve existing player progression, quests, owned content and updated level state.

Overview

ROLE: Senior Game Developer — Project Architecture & Core Systems

Animal Tycoon is a production mobile zoo-management simulation developed in Unity for Android and iOS. Players expand their zoo by unlocking exhibits, purchasing and caring for animals, feeding them through a physics-based interaction system, completing quests, and managing an in-game economy. I architected and implemented the core gameplay systems, including exhibit progression, animal AI, visitor navigation, quests, economy and persistent game state. I also integrated the production systems for advertising, in-app purchases, analytics, Remote Config and cross-platform mobile support.

Gameplay Loop

Earn currency→ Unlock exhibit→ Buy animal→ Feed & care→ Complete quest→ Expand zoo

Key Highlights

  • Architected the complete zoo progression and exhibit-management loop, from unlocking enclosures through quest- and level-gated expansion.
  • Developed animal AI with hunger, survival and food-detection behaviour connected to a Rigidbody-based feeding system with projectile-arc aiming.
  • Created NavMesh-based visitor navigation with walk/idle animation states, obstacle avoidance and stuck/collision recovery.
  • Implemented a persistent JSON save and economy system that reconstructs full gameplay state and uses XOR-style obfuscation to discourage casual save-file tampering.
  • Built the monetization and live-operations pipeline with AppLovin MAX, Unity IAP, Firebase Analytics and Remote Config, including exponential-backoff ad retries and purchase restoration.
  • Optimized Android performance using device-memory-based quality scaling and delivered iOS support with App Tracking Transparency and safe-area handling.

Core Systems

✓ Zoo Progression & Exhibit Management (Script)

Controls the main progression loop from locked zoo areas to active, populated exhibits.

  • Unlocks exhibits, processes animal purchases and spawns animals in the correct enclosures
  • Loads and saves exhibit unlock and purchase state through persistent JSON data
  • Replaces locked-area prefabs with active arena prefabs at runtime
  • Connects unlocked exhibits to animal spawn points, food points and cutscene triggers
  • Tracks feeding, cleaning and exhibit-unlock quests, with level-gated access to new animals, exhibits and features
✓ Animal AI & Physics Feeding (Script)

Combines hunger-driven animal behaviour with a physics-based feeding interaction.

  • Implements cannon-based aiming, turret rotation and a projectile-arc preview for Rigidbody food throws
  • Tracks active food per exhibit and notifies the relevant animal AI when food lands
  • Runs hunger and survival values per animal so animals detect, approach and consume available food
  • Persists feeding state and remaining food values across sessions
✓ Visitor AI & Navigation (Script)

Populates the zoo with visitors that move between exhibits and react reliably to the environment.

  • Uses NavMeshAgent pathfinding between visitor destinations
  • Triggers walk and idle animation states according to movement
  • Tunes obstacle avoidance and implements stuck/collision recovery
✓ Quest, Tutorial & Retention Systems (Script + Integration)

Guides players through the first session and supports continued progression and return visits.

  • Implements a five-stage tutorial with interaction gating so each required action is completed before the next stage
  • Tracks tutorial completion and drop-off through funnel analytics
  • Schedules a multi-stage local-notification campaign through Day 28 to support player retention
  • Includes an always-on gameplay minimap and a separate full-screen map for wider environment navigation
✓ Economy & JSON Persistence (Script)

Provides a centralized economy and persistence layer shared across progression, rewards and purchases.

  • Handles starting cash, currency addition/deduction and a separate ticket currency for zoo entry
  • Persists animals, coins, food, quests, levels and exhibit unlocks through structured JSON data
  • Reconstructs the complete runtime game state when a session starts
  • Uses XOR-style obfuscation to discourage casual modification of local currency data
  • Synchronizes animated coin collection and UI updates using DOTween/LeanTween
  • Routes rewarded-ad and IAP payouts through the same economy layer
  • Supports Silver, Gold and Platinum ticket tiers, with generation values tunable through Remote Config
✓ Monetization & Live Operations (Third-Party Integration)

Connects advertising, purchases, analytics and remotely configurable values into one production pipeline.

  • Integrates AppLovin MAX rewarded, interstitial, banner and app-open advertisements
  • Uses exponential-backoff retry handling for failed ad-load requests
  • Implements Unity IAP consumable currency packs and non-consumable unlocks
  • Restores non-consumable purchases after reinstall or device change
  • Uses Firebase Analytics for gameplay events, tutorial funnels and ad-revenue impression logging
  • Uses Remote Config for live-tunable gameplay and monetization values, with Google Play plugin support for store services
✓ Vehicle & Input Systems (Script)

Adds a purchasable, driveable visitor buggy with its own camera, input and minimap behaviour.

  • Builds a rideable buggy that transports visitors through the zoo
  • Connects buggy ownership to the Unity IAP non-consumable and restore-purchase flow
  • Reassigns Cinemachine camera targets when entering or exiting the vehicle
  • Switches Unity Input System control schemes between on-foot and buggy movement
  • Transfers minimap ownership and places the player safely when exiting
✓ Animal Delivery Interaction (Script)

Adds an interactive puzzle to the animal-delivery and exhibit-unlock flow.

  • Connects world-space screw-removal interactions to UI completion tracking
  • Tracks each side of the delivery panel independently before marking the interaction complete
  • Sequences Cinemachine cameras from the puzzle view into the final animal reveal
✓ Mobile Optimization & Platform Support (Script)

Adapts visual quality and platform behaviour for production Android and iOS releases.

  • Scales quality according to available device memory on Android
  • Uses a shorter camera far-clip range on 3 GB devices and an extended range on 4 GB+ devices
  • Tunes LOD bias per device tier to balance scene visibility and performance
  • Implements App Tracking Transparency support on iOS
  • Handles safe areas for notched iPhone and iPad screens

Overview

ROLE: Senior Game Developer — Project Architecture & Core Systems

Alien Deep Sea Diver Game is a production Android and iOS underwater survival game developed in Unity. Players explore submerged environments, manage oxygen and depth, gather resources, craft survival equipment, complete objectives and progress through level-based content. I built the project-specific gameplay architecture and systems, including underwater-state handling, oxygen and depth mechanics, inventory, equipment, quick slots, crafting, resource scanning, tasks, objectives, XP progression and persistent save data. I also integrated the mobile production services for advertising, analytics, Remote Config, attribution and platform deployment.

⚙

Framework note: I built the project-specific gameplay architecture and systems in Unity, using Invector for the controller foundation and third-party SDKs for mobile production services.

Gameplay Loop

Explore the ocean→ Manage oxygen→ Scan & collect→ Craft equipment→ Complete objectives→ Gain XP & progress

Key Highlights

  • Built underwater-state handling with oxygen depletion, depth tracking, drowning feedback and real-time HUD updates.
  • Developed categorized inventory, equipment slots and underwater quick-slot item handling.
  • Implemented ScriptableObject-driven crafting recipes with ingredient validation, resource consumption and crafted-item output.
  • Built task, objective, XP and level-progression systems with prerequisites and persistent completion state.
  • Implemented JSON Save Data and PlayerPrefs persistence for player progression, inventory and objective state.
  • Integrated Firebase Analytics, Remote Config, AppLovin MAX and Tenjin for production mobile support.

Core Systems

✓Underwater Movement & Dive State(Framework Extension + Script)

Extended the controller foundation with the underwater-state logic required by exploration and survival gameplay.

  • Tracks when the player enters water and becomes fully submerged
  • Activates underwater gameplay controls, quick slots and HUD elements while diving
  • Changes player interaction behaviour when surfacing or leaving the water
  • Connects underwater state with equipment handling and progression systems
✓Oxygen, Depth & Drowning Feedback(Script + UI)

Built the primary survival layer that measures dive depth and communicates remaining oxygen to the player.

  • Drains oxygen while the player remains underwater
  • Calculates depth relative to the water surface
  • Updates oxygen sliders, percentage text and depth indicators in real time
  • Triggers low-oxygen and drowning feedback through the gameplay UI
✓Inventory, Gear & Quick Slots(Script + ScriptableObjects)

Implemented categorized item storage and equipment handling for survival tools, resources, food and wearable gear.

  • Separates equipment, gear, resources and food into defined inventory categories
  • Supports gear slots for suit, fins, oxygen tank, gloves and chip equipment
  • Allows usable underwater items to be assigned to quick slots
  • Connects pickup, equip, drop and held-item behaviour with the world interaction system
✓Crafting & ScriptableObject Recipes(Script + ScriptableObjects)

Built a data-driven crafting system that connects recipe requirements with inventory consumption and progression.

  • Defines crafted items and ingredient requirements through ScriptableObject recipes
  • Validates resource availability before crafting
  • Consumes required ingredients and adds the crafted result to inventory
  • Updates connected task, objective and feedback systems after crafting
✓Tasks, Objectives, XP & Level Progression(Script)

Implemented guided progression that activates level-specific goals and connects player actions with XP and unlock flow.

  • Loads tasks and objectives for the active progression level
  • Supports prerequisites, resource collection and crafting objectives
  • Records objective completion and updates task interfaces
  • Awards XP and coordinates pending level-up confirmation before unlocking later content
✓JSON Save Data & PlayerPrefs Persistence(Script)

Used local persistence to restore progression and item state across application sessions.

  • Stores structured player-level and inventory data through JSON serialization
  • Stores task and objective completion state through PlayerPrefs
  • Restores equipped items, quick-slot selections and progression state during loading
  • Connects save updates with inventory, crafting, scanning and level progression
✓Resource Scanning & HUD Navigation(Script + UI)

Built resource-discovery and navigation feedback to help mobile players locate useful underwater interactables.

  • Tracks nearby scannable and collectible resources
  • Displays navigation markers and off-screen guidance for relevant world targets
  • Connects scanning state with item discovery and progression
  • Coordinates pickup interactions with inventory and objective updates
✓Story, Timeline & Mobile UI Flow(Timeline + UI)

Implemented the presentation flow that connects story sequences, loading, gameplay and the primary mobile interfaces.

  • Uses Unity Timeline for staged story and cutscene sequences
  • Coordinates image-based dialogue and gameplay transitions
  • Built main menu, loading, pause, gameplay, inventory, crafting and task interfaces
  • Connects mobile UI state with underwater gameplay and progression
✓Monetization, Analytics & Remote Config(Third-Party Integration + Script)

Integrated the production services used for advertising, analytics, attribution and remote tuning.

  • Integrated AppLovin MAX advertising flows for the mobile release
  • Instrumented gameplay and production events through Firebase Analytics
  • Connected selected values with Firebase Remote Config for production tuning
  • Integrated Tenjin attribution and impression-level ad revenue tracking
  • Prepared the project for Android and iOS deployment

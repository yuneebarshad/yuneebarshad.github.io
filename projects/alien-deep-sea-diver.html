Overview

ROLE: Senior Game Developer — Survival Systems, Progression & Mobile Production

Alien Deep Sea Diver Game is a production mobile underwater survival and crafting game developed in Unity for Android and iOS. I integrated Invector as the locomotion and swimming foundation, then built the project-specific gameplay layer around it, including interface-based interactions, underwater survival, inventory and quick slots, resource scanning, ScriptableObject-driven crafting, tasks and objectives, XP progression, persistent save data, mobile UI and production SDK integrations. The project also features a guided onboarding sequence that teaches the complete survival and crafting loop before transitioning into unrestricted exploration.

⚙

Framework note: Invector provides the locomotion, swimming, stamina/health and input foundation. I kept the game-specific systems separate and extended that base with custom survival, interaction, inventory, scanning, crafting, progression, persistence and UI systems. Stylized Water 2 and Sickscore HUD Navigation are integrated third-party foundations.

Gameplay Loop

Crash & repair escape pod→ Learn diving & oxygen→ Explore underwater→ Scan unknown resources→ Gather materials→ Craft survival equipment→ Complete tasks & objectives→ Earn XP & level up→ Unlock new world content

  • Architected an interface-based raycast interaction system for pickup, use, scanning, equipment and crafting.

Core Systems

✓Invector Integration & Underwater Survival(Framework Extension + Script)

Extended Invector's locomotion and swimming foundation with a custom underwater survival layer connected through event-driven gameplay integration.

  • Connects custom systems to Invector swimming, stamina/health, mobile input and water-state events
  • Drains oxygen while the player is submerged and provides protected tutorial oxygen behaviour
  • Calculates depth relative to the submersion point and reports ascent/descent direction
  • Updates oxygen, depth, quick-slot and HUD behaviour from underwater state changes
  • Provides low-oxygen and drowning visual feedback through the gameplay HUD
✓Interface-Based Interaction Architecture(C# Interfaces + Raycasting)

Architected a shared camera-raycast interaction pipeline so the player controller can work with different object types through reusable C# interfaces instead of hard-coded per-object logic.

  • Uses interfaces including IPickable, IUsable, ICraftable, IScannable, IEquippable and IDisplayable
  • Supports contextual Pick Up, Hold, Use, Craft and Drop actions through the same targeting flow
  • Allows new interactive objects to expose capabilities without changing the central player-targeting code
  • Supports press/release interactions for hold-based mechanics such as scanning and wire repair
✓Onboarding FSM & Escape-Pod Repair(Finite State Machine + Gameplay)

Engineered a state-driven guided onboarding flow that teaches the complete survival loop while temporarily controlling input, UI and environment state.

  • Covers movement, camera control, targeting, oxygen, swimming, gathering, crafting, inventory, quick slots and level progression
  • Dynamically attaches focused tutorial helpers and advances through gameplay events and callbacks
  • Restricts unrelated controls, highlights required UI, activates triggers and coordinates timed tutorial transitions
  • Includes particle-collision fire suppression with progressive VFX feedback and task completion
  • Includes an interruptible hold-to-repair wire interaction with animator-driven progress, rewind behaviour, audio and persistent repair state
✓Inventory, Equipment & Quick Slots(Script + ScriptableObjects + UI)

Developed an instance-based inventory architecture for equipment, gear, resources and food, with persistent item identity and mobile equipment workflows.

  • Assigns unique per-instance IDs to acquired items and publishes inventory change events
  • Separates Equipment, Gear, Resources and Food into category-specific inventory views
  • Provides five configurable underwater quick slots for usable equipment
  • Supports typed Suit, Fins, Oxygen Tank, Gloves and Chip gear slots with drag-and-drop validation
  • Instantiates selected tool prefabs in the player's hand and supports dropping items back into the world
✓Resource Scanning & HUD Navigation(Gameplay + Third-Party HUD Integration)

Built a persistent resource-discovery mechanic and connected it with level-aware underwater navigation feedback.

  • Requires the scanner to be assigned to and selected from a quick slot before use
  • Uses camera raycasting and a four-second hold interaction that resets if the target is lost
  • Persists scanned item IDs and unlocks names, descriptions and normal pickup behaviour for matching resource types
  • Displays scan progress and discovered-item detail UI
  • Integrates Sickscore HUD Navigation for distance-gated resource markers alongside compass, radar and minimap presentation
✓ScriptableObject Crafting Architecture(Script + ScriptableObjects + Presentation)

Built a data-driven crafting pipeline that connects recipe data, inventory validation, progression and an animated 3D crafting-station presentation.

  • Defines recipe results, ingredient quantities, categories and task mappings through ScriptableObjects
  • Validates required materials, consumes the correct quantities and adds the crafted result to inventory
  • Builds recipe and ingredient UI from data and reflects current material availability
  • Transitions the camera to the crafting station and coordinates animation, particles, sound and dissolve effects
  • Spawns an interactive crafted-item presentation whose pickup completes the mapped task without duplicating inventory output
✓Tasks, Objectives & XP Progression(Event-Driven Progression)

Implemented separate persistent tasks and ordered objectives, then connected them to XP, level confirmation and level-specific world activation.

  • Tasks represent persistent goals and award XP, while objectives provide immediate ordered instructions
  • Supports objective prerequisites, priorities, resource-gathering tracking and craft-completion tracking
  • Persists task completion and updates progression through gameplay and inventory events
  • Uses pending level-up confirmation before replacing tasks and activating the next level's world content
  • Coordinates authored progression across five content levels with level-specific resources and dialogue
✓JSON Save Data & Persistent State(Serialization + PlayerPrefs)

Implemented local persistence across structured JSON saves and smaller PlayerPrefs-backed progression flags.

  • Persists inventory entries, equipment state, quick slots, gear slots and scanned item IDs through JSON
  • Persists player level and remaining XP in structured save data
  • Stores task completion, objective history, tutorial completion and escape-pod repair state through smaller persistent flags
  • Uses stable item IDs to reconstruct ScriptableObject-backed runtime items across sessions
  • Connects save updates with inventory, discovery and progression systems
✓Mobile UI, Rendering & Production SDKs(UI + URP + SDK Integration)

Integrated the mobile UI, rendering and production-service layer around the core gameplay systems.

  • Built contextual mobile HUD flows for interaction, inventory, crafting, tasks, XP, scanning, oxygen, depth, pause and failure states
  • Configured URP 14.0.12 with Stylized Water 2 underwater rendering and a lower-cost iOS quality profile that reduces HDR, MSAA, shadows and lighting costs while retaining required depth/opaque textures
  • Integrated AppLovin MAX interstitial and MREC advertising with active placement timing and retry handling
  • Integrated Firebase Analytics and Remote Config for ad lifecycle telemetry and remotely configurable ad timing
  • Integrated Tenjin attribution, iOS App Tracking Transparency handling, Meta SDK initialization and iOS post-build processing
